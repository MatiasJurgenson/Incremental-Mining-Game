# Incremental Mining Game

A 2D mining game made for the course Computer Graphics (MTAT.03.015)

## Running the game

On Linux:
```
  $ cmake --preset linux-config
  $ cmake --build --preset linux
  $ ./build/linux/game
```

On Windows:
```
  $ cmake --preset windows-config
  $ cmake --build --preset windows
  $ ./build/windows/game
```

The Windows preset requires CMake 4.5 or newer and Visual Studio 18 2026.

To move around, use arrow keys or WASD.
